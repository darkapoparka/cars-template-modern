# Desktop page hero photographs

Generated on 7 October 2026 for the Modern template's Services, About and Contact desktop mastheads. Each page has a distinct subject: keys and paperwork for Services, an interior architectural view for About, and an arrival courtyard for Contact.

These are illustrative template scenes, not photographs of an actual dealer or its premises. There are no new dealer identities, staff or testimonials. Dealer-specific approved imagery can replace each role through `artwork.desktopPageHeroes`; existing personalized shared scenes and cutouts remain authoritative unless page-specific imagery is supplied.

Each page directory preserves the unmodified generated PNG and the complete prompt in `generation.json`. `assets.json` records original and served file dimensions, byte sizes and SHA-256 hashes. Served WebPs use quality 90 encoding only; no recolouring, compositing, retouching or source cropping was applied. The existing responsive desktop banner determines the displayed crop.

Home and inventory discovery vehicle artwork, mobile composition, masthead geometry, copy and actions are unchanged.
