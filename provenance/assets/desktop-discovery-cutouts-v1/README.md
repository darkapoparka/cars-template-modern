# Desktop discovery cutouts

The owner approved the light Home/Cars proposal on 5 October 2026. Its G-Class and Urus are the existing Import template's profile cutouts, copied byte-for-byte to Modern's public desktop assets. No new image generation or image editing was performed for this implementation. The left vehicle is mirrored in presentation only.

`assets.json` records the original sources, served paths, original dimensions, byte counts and SHA-256 hashes. Modern's `site-artwork.ts` owns the reusable default pair; dealer copies can supply their own pair through the public artwork contract. The previously rejected generated showroom proposal remains preserved in the proposal evidence directory.
