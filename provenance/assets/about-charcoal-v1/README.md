# About illustrations: charcoal v1

The four approved blue illustrations were supplied as editing references to the built-in `image_gen.imagegen` tool on 5 October 2026. The request preserved each subject and composition while replacing blue surfaces with satin charcoal and neutral silver. Generation used a transparent background.

The original generated PNGs are preserved byte-for-byte as `choice-source.png`, `details-source.png`, `budget-source.png` and `viewing-source.png`. The preceding blue references and their provenance remain available.

The public derivatives are transparent 384 × 384 WebP files at quality 90 and alpha quality 100. Processing only resized and encoded the generated artwork; it did not crop, recolour or replace the background. Together the four served files occupy 98,730 bytes.

[generation.json](generation.json) records every prompt, reference, original source, generated output, dimension, hash, transparency check and derivative path. Public configuration consumes these through the `aboutBenefits` illustration roles.
