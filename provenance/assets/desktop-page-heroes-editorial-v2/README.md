# Desktop page hero photographs - second set

Generated with `image_gen.imagegen` on 8 October 2026 for Modern's Services, About and Contact mastheads. The owner rejected the flat graphite Services banner and the shorter Contact frame. All three pages now share a 352 px photographic header, with distinct but coordinated compositions and restrained overlays.

Services shows detailed automotive bodywork and a delivery setting. About shows an interior showroom reception. Contact shows the arrival forecourt and entrance. Natural sunlight, material detail and subtle greenery supply colour without changing the configured interface palette.

These are fictional illustrative template scenes, not photographs of an actual dealer or its premises. They add no customer identity, staff or testimonial claims. Dealer-approved photography can replace each role through `artwork.desktopPageHeroes`; supported existing shared artwork overrides remain authoritative.

Each page directory preserves the unmodified generated PNG and full prompt in `generation.json`. `assets.json` records original and served dimensions, byte sizes and SHA-256 hashes. WebP quality 90 encoding retains the source dimensions and composition; no recolouring, retouching, compositing or source cropping was applied. Responsive CSS determines the displayed crop.

The previous v1 files and provenance remain preserved. Home/Cars artwork, mobile composition, copy and action behaviour are unchanged.
